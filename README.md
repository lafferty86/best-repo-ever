## 🐴 Hoofprints

A super-fun, all-in-one horse journal for young riders — no install, no account, no internet needed. Just open [`index.html`](index.html) in any browser (double-click it!).

**What's inside:**
- **My Stable** — profile cards for every horse she's ridden: breed, size (pony/horse/mini/🦄 unicorn), coat color, personality chips, favorite treat, and notes
- **Ride Journal** — log every ride: activity, minutes, mood (😴 → 🦄 MAGICAL), and the best moment
- **Badge Wall** — 14 prize rosettes earned automatically (First Hoofprint, Trail Blazer, Show Stopper, Legend of the Barn…)
- **Fun Stuff** — daily horse fact, dream-horse name generator, and a button that sends a pony galloping across the screen
- Confetti when good things happen 🎉

Everything saves automatically on the device (localStorage), with **Save/Load barn to a file** buttons for backups or moving between devices. Works in light and dark mode.
