# best-repo-ever

A project using [GitHub Flow](CONTRIBUTING.md) for version control.

## Autosave

This repo carries a drop-in [autosave bundle](docs/AUTOSAVE.md): a `Stop` hook
that commits and pushes every change after each Claude Code turn, so a session's
work is always on GitHub. Add it to any other repo with `install-autosave.sh`.
