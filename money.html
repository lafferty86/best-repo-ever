📊 Google Sheet storage

Use a Google Sheet as FIREside's storage: once connected, the app loads your latest data from the sheet when it opens and saves back automatically after every change — same data on every device, plus live Dashboard, Checklist, and History tabs in the sheet. One-time setup, ~2 minutes.

  1. Open your Google Sheet → Extensions → Apps Script.
  2. Delete any starter code, paste the script below, and save.
  3. Deploy → New deployment → Web app — Execute as: Me, Who has access: Anyone. "Anyone" means anyone with the secret deployment URL — keep it private, or set a passphrase below for an extra lock.
  4. Copy the Web app URL (ends in /exec) and paste it here.
